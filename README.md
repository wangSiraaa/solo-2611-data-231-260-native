# 可变长记录堆文件的稳定RID与页内压实

本目录仅含任务输入与可运行测试设施，不含待实现的处理器。

一个离线数据存储组件需要更新不同长度的二进制记录，但外部保存的记录地址不能因页内压实或增长搬移而失效。请用Python 3.11实现小型slotted-page堆文件，提供insert、get、update、delete、compact、scan及inspect。输入已有原始payload文件和操作序列；页面固定256字节，单记录最多180字节，内容是不透明bytes，不是文本或JSON。
记录身份RID至少包含锚定页号、slot号与代际。slot目录与页内payload分离，压实可以移动字节但不得改变活记录RID。删除后slot可复用，但旧RID必须仍被拒绝，不能指向新插入数据。长度超过页面可用空间时可迁往另一页并让原锚点保存转发；多次增长搬移不能累成长链，get最多访问锚点及一个目标数据页。单条payload不跨多个数据页，不要求压缩。
先使用已有合适空闲空间，页内总空闲足够但碎片阻挡时应能压实后放入；只有现有页无法容纳才增加页。明确slot目录和转发记录的空间开销，页边界、payload区和目录区不得重叠。inspect逐页核对slot状态、空闲区间及转发目标，scan每个逻辑活记录只输出一次，不能把转发目标又当新记录导出。
格式版本、页大小、slot代际与必要目录均持久保存，关闭重开后RID及内容仍有效。非法RID、重复删除、超长payload或损坏页结构应明确报错；不通过扫描全部内容猜测一个失效RID原来是谁。允许扫描页元数据寻找空间，不把全部payload放进内存后重写整个文件。只做单进程串行调用，不承诺多记录事务、WAL、崩溃恢复或并发访问。
运行给定序列验证增长、缩短、删除、空洞压实和重开，额外构造同slot复用及连续三次迁移，逐字节与独立内存字典对照。记录实际增加页、压实和转发操作；证明有足够页内空闲时没有无故扩文件，以及旧RID未复活。交付源码、格式说明、检查报告和完整命令；不实现排序索引、缓冲池或通用数据库。
